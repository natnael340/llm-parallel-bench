On the complete graph benchmark (2000 nodes, ~4M directed edges), the parallel version achieved a 7.33× speedup over the sequential baseline (188.45 ms vs 1380.80 ms). This improvement stems from the direction-optimizing BFS strategy, switching between top-down and bottom-up traversal based on frontier density. However, this approach sacrifices traversal order fidelity—nodes within each level are sorted by ID rather than preserving the discovery order of the sequential algorithm.
The implementation performed poorly on deep graphs (linear chain of 10,000 nodes), running 110.7× slower than sequential (4097.52 ms vs 37.01 ms). This is expected: deep graphs have single-node frontiers at each level, eliminating any opportunity for parallelism while incurring thread synchronization overhead on every level transition.
