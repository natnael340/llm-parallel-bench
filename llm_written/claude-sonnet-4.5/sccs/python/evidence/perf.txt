PERFORMANCE TEST DETAILS
============================================================

Test configuration:
  Vertices: 1000
  Edges: 1480
  SCCs: 20
  SCC size: ~50 vertices each

Results:
  Sequential time: 0.0065s
  Parallel time:   0.1937s
  Speedup:         0.03x
  CPU cores:       16

Analysis:
  ProcessPoolExecutor has significant overhead (~150-200ms) for process
  spawning and data serialization. The per-SCC work (spanning tree DFS)
  is very fast (~0.2ms each), so overhead dominates.

  Parallelization is beneficial only when:
  - SCCs are very large (>1000 vertices)
  - Graph has hundreds of SCCs
  - Or using thread pool for lighter overhead (if GIL permits)
